# HelpDesk PWA — Database

## Objetivo

Desenvolver a camada de persistência local do HelpDesk PWA utilizando JavaScript e IndexedDB.

## Responsabilidades

- Modelagem dos dados dos chamados.
- Implementação do armazenamento local.
- Operações CRUD: cadastrar, consultar, atualizar e excluir.
- Persistência e recuperação dos registros.
- Suporte ao funcionamento offline.
- Testes e documentação da camada de dados.

## Responsável

Eliézer — Banco de Dados e Persistência.
